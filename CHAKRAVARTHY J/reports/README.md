# Milestone 2 Sample Report

- `Cloth_Analysis_Report.docx` — full report generated by running the actual
  Milestone 2 pipeline (feature_extraction → material_classifier →
  waste_classifier) on `sample_denim_garment.jpg`. Includes a Visual Analysis
  Outputs section with the images below embedded and captioned.
- `sample_denim_garment.jpg` — the sample garment image used for this run.
- `sample_analysis_result.json` — raw JSON output of the pipeline (features,
  material classification, waste classification) that the report was built from.
- `images/` — every visualization from the report as a standalone downloadable
  PNG, generated straight from the real feature-extraction numbers (not
  illustrative mockups):
  - `01_resized_input.png` — the 128×128 image actually fed to the model
  - `02_grayscale.png` — luma channel used for texture/edge analysis
  - `03_edge_pattern_map.png` — gradient-magnitude map (pattern/weave regularity)
  - `04_texture_damage_heatmap.png` — local-variance heatmap (blue = smooth, red = rough)
  - `05_damage_contamination_overlay.png` — damage (red) and contamination (yellow)
    regions overlaid on the original image
  - `06_dominant_color_swatch.png` — flat swatch of the mean RGB color

To generate a report for your own garment photo instead: run the app
(`cd backend && python run.py`), log in, go to the Analysis page, upload a
photo, and the same feature/material/waste breakdown and visuals will be
computed live and saved to analysis history.
