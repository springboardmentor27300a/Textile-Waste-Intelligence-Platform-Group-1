# Textile Waste Intelligence Platform

An AI-powered local web platform for textile waste analysis, material classification, recyclability assessment, recycling recommendations, and sustainability intelligence.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI
- Database: PostgreSQL
- Machine Learning: PyTorch
- Image Processing: OpenCV / Pillow
- Analytics: Pandas / NumPy
- Visualization: Chart.js
