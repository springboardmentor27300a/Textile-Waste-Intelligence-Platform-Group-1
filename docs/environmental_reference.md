# Environmental Reference Factors

The sustainability engine estimates environmental savings using literature-informed Life Cycle Assessment (LCA) reference values.

## Data Sources

- Textile Exchange
- Higg Materials Sustainability Index (MSI)
- Ecoinvent Database
- Water Footprint Network
- IWTO Environmental Reports
- Carbonfact Sustainability Database

## Units

CO₂ Saved → kg CO₂e / kg textile

Water Saved → Liters / kg textile

Landfill Diverted → kg / kg textile
