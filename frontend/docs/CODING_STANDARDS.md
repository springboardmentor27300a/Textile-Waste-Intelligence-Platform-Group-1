# TWIP Coding Standards

## Naming

Components:
PascalCase

Example:
LoginForm.jsx

Hooks:
camelCase

Example:
useAuth.js

Variables:
camelCase

Constants:
UPPER_CASE

## React

One component per file.

Keep components under 200 lines where practical.

Move reusable logic into hooks.

## Styling

Tailwind CSS only.

No inline styles unless absolutely necessary.

Use project colors only.

## Icons

Lucide React only.

## Forms

React Hook Form

Zod Validation

## API

Axios

## State

Context API

React Query

## Comments

Only explain WHY.

Never explain obvious code.

## Git

One feature = One commit.
